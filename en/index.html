QR Toolkit.

From data to a QR code. From QR to the next node.

Generate QR codes and read their contents inside your n8n instance. The node processes your data locally.

Example workflow

Generate, then read.

Download n8n workflow ↓
  1. 01

    Start the workflow

    Import the example JSON into n8n. The manual trigger starts the two QR Toolkit nodes.

    Manual Trigger
  2. 02

    Generate the PNG

    The first node encodes the sample URL and writes a PNG to the binary property data.

    Generate QR Code
  3. 03

    Read the value

    The second node reads the same PNG. The next step can access its decoded value in qrContent.

    Read QR Code

Output formats

PNG · SVG · Base64 PNG Data URL

Reader inputs

Binary PNG or a PNG data URL. Use clean images with an axis-aligned code.

Installation

Add it to n8n.

For self-hosted instances with community nodes enabled.

In Settings → Community Nodes → Install, enter the package name.

@cyberace/n8n-nodes-qr

Complete the installation and look for QR Toolkit in the node picker.
