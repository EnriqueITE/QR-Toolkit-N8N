Nodo comunitario para n8n

QR Toolkit.

De un dato a un QR. Del QR al siguiente nodo.

Genera códigos QR y lee su contenido dentro de tu instancia de n8n. El nodo procesa los datos localmente.

Generar y volver a leer.

Descargar flujo para n8n ↓
  1. 01

    Inicia el flujo

    Importa el JSON del ejemplo en n8n. El disparador manual pone en marcha los dos nodos QR Toolkit.

    Manual Trigger
  2. 02

    Genera el PNG

    El primer nodo codifica la URL de ejemplo y entrega el archivo PNG en la propiedad binaria data.

    Generate QR Code
  3. 03

    Recupera el valor

    El segundo nodo lee ese mismo PNG. El contenido queda disponible para el siguiente paso en qrContent.

    Read QR Code

Formatos de salida

PNG · SVG · Base64 PNG Data URL

Entradas de lectura

PNG binario o Data URL de un PNG. Usa imágenes nítidas con el código alineado a los ejes.

Instalación

Añádelo a tu n8n.

Para instancias autohospedadas con nodos comunitarios habilitados.

En Settings → Community Nodes → Install, introduce el nombre del paquete.

@cyberace/n8n-nodes-qr

Completa la instalación y busca QR Toolkit en el selector de nodos.
